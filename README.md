# The Little Book of Kaggle 1st Place Solutions

Kaggleの1位解法を、課題の理解から、動く基準解法、優勝した構成、そこへ自力で辿り着くための観察と実験まで、一続きで読むための小さな本です。

**[本を読む（PDF）](The_Little_Book_of_Kaggle_1st_Place_Solutions.pdf)** · **[別のコンペで本を作る（設計書）](設計書.md)**

## 収録するコンペ

1. Drawing with LLMs
2. AI Agent Security - Multi-Step Tool Attacks
3. The Pokémon Company - PTCG AI Battle Challenge Simulation
4. Kaggriculture
5. ARC Prize 2026 - ARC-AGI-3

各章は次の4節で構成しています。

1. タスク
2. 基本解法
3. 1位解法
4. 自力で1位解法に辿り着くには

小さな具体例から読み始め、採点方法と制約を確かめ、1位解法の各工程が何を改善するかを追います。逆算した探索の手順は本書の提案として示し、勝者本人が実際にたどった開発履歴とは区別しています。公式仕様、本人報告、公開コードで確認したこと、本書の説明例、実施済みの確認と未実施の課題も区別しています。

## PDFについて

日本語・白黒・本文9ptの閲覧版です。表紙、しおり、クリックできる目次、参考資料へのリンクを備えています。書籍内のページ番号を保っているため、目次の番号からも参照できます。
